# Ôn thi trắc nghiệm DevOps Fundamental (IT209)

3 đề × 40 câu, mỗi đề 30 phút, kèm Đề trộn ngẫu nhiên từ ngân hàng 120 câu.
Chủ đề: VPS & Nginx, Git, Linux, Docker, Docker Compose, CI/CD (GitHub Actions).

**Làm bài online:** https://ngthekien.github.io/IT209_DevOps_Quiz/

- Phím `1–4` / `A–D` chọn đáp án, `←` `→` chuyển câu, `F` đánh dấu.
- Đáp án xáo trộn mỗi lần làm.
- Nộp bài xem điểm theo chủ đề và giải thích từng câu sai.
- Điểm cao nhất lưu trên trình duyệt của mỗi người.

Muốn thêm câu hỏi: sửa `questions.js`, mỗi câu theo mẫu
`Q("Chủ đề", "Câu hỏi", ["A", "B", "C", "D"], <chỉ số đáp án đúng 0-3>, "Giải thích")`.
